# Orion Note Bilingual Product Spec

## Product Positioning

Orion Note is a bilingual meeting-note assistant for small research teams.
The first public pilot is planned for Singapore and Taipei.
The product is not designed for medical diagnosis or legal representation.

## Core Features

The MVP supports live transcript cleanup, action-item extraction, and bilingual summary generation.
Offline mode supports reading saved notes, but it does not support new speech transcription.
The maximum meeting duration in the pilot plan is 90 minutes.

## Privacy Rules

Audio files are deleted after 14 days by default.
Users can shorten retention to 3 days in the workspace settings.
Enterprise administrators can disable external sharing for all projects.

## Release Plan

Private beta starts on 2026-05-20.
Public pilot starts on 2026-07-01.
