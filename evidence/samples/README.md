# Sample Documents

This folder contains fixed sample documents for repeatable demos and replay runs.

## Files

- `research_brief.md`
  - default primary demo sample
- `office_notice.txt`
  - smart office scenario sample
- `paper_report.md`
  - source text that can also be converted to PDF later for page-structure demos
- `chinese_llm_spatial_eval.pdf`
  - Chinese academic PDF sample for retrieval, summary, and outline validation

## Notes

- These are repo-safe demo files with no secrets.
- If you need a true PDF sample, convert `paper_report.md` into PDF outside the repo and keep the converted file locally.
