# 研答通 商业化潜力论证

**对应赛题**：无问芯穹赛题一 · 加分项 #2 — 商业化潜力（5 分）。赛题原文：「参赛作品具有潜在的商业化价值（B 端或者 C 端业务潜力均可），**需要充分论证其市场潜力**」。

> 口径声明（先说边界）：本页市场数字为**公开统计量级 + 自下而上估算**，非精确市场调研；定价为可辩护的假设区间，非已成交价格。产品当前是 controlled-alpha，这是**上线节奏**的边界，与"论证市场潜力"不冲突。答辩按此诚实表述（对齐记忆 `feedback_eval_honesty`）。

## 一、目标市场量化（自下而上）

研答通解决的是「读论文/报告时**能答、还能回到证据**」这一刚需，核心人群与场景：

- **在校研究生**：中国在校研究生规模在**数百万量级**（硕博合计，公开统计量级），每人每年精读文献/写综述/开题/答辩是高频刚需。
- **高校教师 / 科研人员**：审稿、追踪文献、指导学生，文献阅读是日常。
- **文献增量**：每年中文学位论文 + 中英文期刊/arXiv 论文是**千万级**新增待读文献池。

| 层级 | 口径 | 量级（公开口径 + 估算） |
|---|---|---|
| TAM | 全体需要"带证据"读文献的研究者/学生 | 在校研究生（教育部公开统计**约 388 万**，2023 口径）+ 高校专任教师/科研人员（**约 200 万级**），核心人群**约 500 万+**；叠加 CNKI 年新增收录文献**千万级**的待读池 |
| SAM | 论文密集学科（理工/医/经管）+ 有经费的实验室/课题组 | **数十万课题组 + 百万级个人**可触达 |
| SOM（首批） | 种子高校的若干重点实验室/院系试点 | **首批数十个课题组**席位订阅 |

**为什么是真实市场而非小众工具**：读文献"说得出处"是学术场景的硬要求（答辩被追问出处、综述要可追溯引用），不是锦上添花；人群基数大、需求高频、付费决策有经费支撑。

## 二、B 端 / C 端路径选择（明确主路径）

**主打 B 端：高校实验室 / 课题组 / 院系按席位订阅**；**C 端（个人研究者 / 答辩季学生）作为增长入口**。

论证理由：

- 科研场景的付费决策权与预算在**导师 / 实验室经费 / 院系**，B 端续费稳定、获客集中、客单价高于个人。
- C 端答辩季 / 开题季有明确自然峰值，适合做低成本获客入口，再向 B 端转化（land-and-expand）。
- 与"controlled-alpha、不做公开 SaaS"不矛盾：B 端按机构受控开通，正好匹配当前发布姿态。

## 三、竞品差异化（唯一差异列）

| 维度 | 通用大模型 | ChatPDF / Readpaper | 知网/数据库 AI 阅读 | **研答通** |
|---|---|---|---|---|
| 能回答文档问题 | ✅ | ✅ | ✅ | ✅ |
| **每条回答可回链 PDF 原页证据** | ✗（常编造/补页码） | 部分（页码，少做逐字校验） | 部分 | ✅ **bbox 级高亮 + 逐字子串校验** |
| **离题/无依据自动拒答** | ✗（倾向硬答） | 弱 | 弱 | ✅ **检索/模型双层拒答** |
| 引用不可伪造（quote 原文校验） | ✗ | ✗ | ✗ | ✅ |
| 端云协同/token 成本可控 | — | — | — | ✅ 长文 ask 平均省 86.6% |

**差异化主张一句话**：竞品比"答得流畅"，研答通比"**答得可验证**"——这正是学术/答辩/审稿场景"说得出处"的刚需，也是替代成本最高的护城河（评委、导师、审稿人都要求可追溯）。

## 四、定价与单位经济（算得过账）

可辩护的定价假设（区间，非成交价）：

- **C 端个人版**：月订阅，定位"一杯咖啡到一顿饭"的低门槛区间（**假设区间 ¥19–39/月**），覆盖答辩季/赶稿期的个人。
- **B 端实验室/院系版**：按席位包年（**假设区间 ¥600–1200/席·年**，高于个人月费×12 折算），含批量文档与协作；付费决策权在导师/实验室经费。

**毛利支撑（关键硬数据）**：成本主项是云端大模型 input token。研答通端侧/近端三层预处理把**长文档 ask 的 input token 平均压缩 86.6%、峰值 93.1%**（单篇论文问答从万级 token 压到百级，见 `evidence/reports/token_compression_eval.md`）。即**每次问答的边际推理成本被压低近一个数量级**，使得：

- 个人订阅在低客单价下仍有正毛利；
- B 端高用量场景毛利随规模放大而稳定（token 压缩让边际成本不随提问量线性膨胀）。

**单位经济小账（受控对照实测口径）**：一次长文 `ask` 实际只上送约 **2,240** input token（直接喂全文是 **9,778**，省 ~77%，见 `evidence/reports/baseline_compare_eval.md`）。按 MaaS 按 token 计费，单次问答的云端边际成本是"分级"而非"元级"——即便 C 端取 ¥19/月、用户月均数十次问答，token 成本占比仍是**个位数百分点**，毛利空间充足；B 端高用量下因压缩使边际成本不随提问量线性膨胀，规模化毛利稳定。

**人民币换算（按 DeepSeek 官方国内报价锚定；无问芯穹 MaaS 实际计费以控制台为准、租户可能享折后价）**：`deepseek-v4-flash` input 单价约 **`¥1/百万 token`**（cache-miss；cached 低至 `¥0.02/百万`，海外口径 `$0.14/M`）。单次 `ask` 上送 2,240 token 的云端 input 成本 ≈ **¥0.002/次**；叠加 output（约 `¥2/百万`）与部分缓存命中，单次总边际成本仍是**厘级**。按月均 50 次问答 ≈ **¥0.1–0.15/月**，对 ¥19/月 C 端定价占比 **< 1%**。结论：**单次问答边际成本与售价相差约 3–4 个数量级，单位经济稳健成立**。（口径红线：单价取公开真实报价、不为对齐结论挑价；封板前以代金券号控制台当日折后价复核，若显著更高则改本结论而非改价。）

这条把"有人用"升级为"**有人付费且单位经济算得过账**"。

## 五、获客路径（低 CAC 的 land-and-expand）

1. **自然峰值入口**：答辩季 / 开题季 / 投稿 deadline 前是文献精读的高峰，以 C 端免费/低价入口获取首批用户。
2. **导师与同门扩散**：一个学生用得好 → 组会推荐 → 实验室扩散 → 导师决策按席位采购（实验室内部口碑传播，CAC 极低）。
3. **从单实验室到院系**：单课题组试点跑通 → 院系级席位采购（land-and-expand），复用同一套受控开通流程。

## 六、分阶段商业化里程碑（不画大饼）

| 阶段 | 目标 | 可验证小目标 |
|---|---|---|
| Alpha（当前） | 受控演示，验证主链路与证据回链价值 | 锁定样例端到端跑通、评测闭环、平台调用留痕 |
| Beta | 2–3 个种子实验室付费试点 | 真实课题组按席位试用、收集留存与续费意愿 |
| 规模化 | 院系级席位采购 | 从单实验室扩到院系、跑通受控批量开通 |

## 七、答辩 30 秒口径

> 研答通主打 **B 端高校实验室席位订阅**（C 端答辩季做入口）：科研场景"说得出处"是刚需，人群是数百万研究生 + 科研人员；我们的差异化不是"答得流畅"而是"**答得可验证**"——每条回答 bbox 级回链原文、逐字校验、离题拒答；**端云协同的 token 压缩（长文 ask 平均省 86.6%）让每次问答边际成本压低近一个数量级**，单位经济算得过账。市场数字是公开量级 + 自下而上估算，不是精确普查。
