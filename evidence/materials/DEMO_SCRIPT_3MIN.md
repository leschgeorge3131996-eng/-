# 研答通 3 分钟演示脚本

## 开场（20s）

大家好，我们的作品叫“研答通”，它是一款面向科研与智能办公场景的个人智能文档助理。它不是普通聊天壳，而是围绕文档上传、解析、问答、提纲生成和日志留存构建的完整闭环。

## 场景痛点（25s）

现实中，用户处理长文时往往有三个痛点：

1. 很难快速读完并提炼重点
2. 即使问答，答案也常常缺少依据
3. 生成汇报提纲或答辩提纲成本很高

我们的目标，就是把这些文档任务整合进一个可演示、可扩展、可验证的助手里。

## 演示流程（90s）

1. 上传一份文档
- 展示系统支持上传 TXT / Markdown / PDF
- 展示当前文档的页数、分块数等信息

2. 做摘要
- 输入摘要指令
- 展示系统返回的结构化摘要

3. 做问答
- 输入基于文档的问题
- 展示系统通过轻量检索选取相关片段
- 展示结果中的引用依据、页码和证据片段

4. 做提纲生成
- 输入汇报或答辩提纲要求
- 展示返回结果

## 技术亮点（35s）

当前系统已经具备这些关键能力：

- 文档页级结构保留
- 文本分块
- 轻量检索
- 结构化引用依据
- 调用日志与统计面板
- demo 模式和证据目录

这说明我们不是单纯调一个模型接口，而是在做一个真正的文档任务链路。

## 结尾（20s）

下一步，我们会继续提升检索质量、优化摘要与提纲的上下文选择，并补齐评测样例和比赛材料，把它从可演示原型进一步推进为更有说服力的参赛作品。
