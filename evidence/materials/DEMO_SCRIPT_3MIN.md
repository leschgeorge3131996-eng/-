# 研答通 3 分钟演示脚本

## 1. 开场（20s）

大家好，我们的作品叫"研答通"，一个面向论文与报告阅读、答辩准备的文档助手。我们和普通聊天工具最大的区别只有一条——**每一条回答都能跳回 PDF 原文证据**。不是生成之后附赠一个页码，而是把"可回链"作为整条链路的硬约束。

## 2. 场景痛点（20s）

答辩和复核里最常见的不是"回答不流畅"，而是"说不出处"。读长文又慢、聊天工具又离开上下文凭印象生成，结论没法验证。我们要解决的，就是让每一个结论都能一键跳回它的来源段落。

## 3. 演示主路径（100s）

**这一段是演示核心，其余任务在 QA 里简要带过。**

推荐优先使用当前已锁定的 gold-sample candidate：

- 文档：`evidence/samples/chinese_llm_spatial_eval.pdf`
- 主问题：`这篇论文主要研究了什么问题？`
- 补充问题：`作者最终的方法排名和总体准确率分别是多少？`
- 拒答问题：`木星有几颗卫星？`

1. **进入示例文档**（10s）——点击首页"示例问答"入口，直接载入这份已准备好的真实中文论文，跳过手动上传。
2. **问一个文档内问题**（20s）——优先使用：`这篇论文主要研究了什么问题？`。系统先检索相关片段，再调用模型作答；检索未命中就直接拒答，不编造。
3. **看回答 + 证据**（25s）——结果面板同时呈现回答正文、引用页码、原文片段。强调这一条：引用不是装饰，而是后端反查过原文的二次校验产物。
4. **打开 PDF 定位**（25s）——点击任一 citation，右侧 PDF 面板跳到对应页码，页面内直接显示证据高亮框；框旁附原文片段文本，即便高亮坐标偏移也不影响证据对齐。
5. **切到第二个 answerable**（10s）——问：`作者最终的方法排名和总体准确率分别是多少？`，展示系统能稳定返回明确数字答案与 citation。
6. **最后演示拒答**（10s）——问：`木星有几颗卫星？`，展示系统直接拒答，而不是编造。

## 4. 技术亮点（30s）

我们做了一件别的聊天工具不会做的事：把"答案 → 证据"当成一条硬约束，穿过四层：

- **解析层**：PyMuPDF 保留页面每一行的坐标
- **检索层**：分块 + 轻量检索 + 未命中就拒答
- **生成层**：模型必须声明用了哪些 chunk、引用哪句原文
- **呈现层**：原文片段在 PDF 页面内直接定位，并在旁附文本片段

四层都跑通，这条链才成立。

## 5. 结尾（15s）

我们已经把"可回链问答"端到端跑通，并在真实论文上验证。摘要与提纲任务也一并支持，但今天的 demo 聚焦在最能代表我们差异点的一条：**每一条回答都指得回原文。**
