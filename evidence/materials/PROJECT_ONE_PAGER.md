# 研答通 一页式项目说明

## 作品定位

研答通是一款面向科研与智能办公场景的个人智能文档助理。用户上传文档后，系统能够围绕文档内容完成摘要、问答和提纲生成，并逐步增强为带检索、带引用、可评测的端云协同文档助手。

## 目标用户

- 科研学习场景中的学生、研究者
- 需要快速理解长文并生成汇报材料的知识工作者
- 需要基于文档快速问答和提炼重点的办公用户

## 场景痛点

- 长文阅读成本高，难以快速抓住重点
- 问答时常常脱离原文，答案难以验证
- 汇报提纲、答辩提纲整理成本高
- 传统聊天工具缺少文档处理闭环，难以证明答案依据

## 当前核心能力

1. 支持上传 `TXT / Markdown / PDF`
2. 支持文档摘要、问答、提纲生成
3. 支持真实云端模型调用与本地调用日志记录
4. 支持文档页级结构保留与文本分块
5. `ask` 任务已接入轻量检索，并能返回结构化引用依据
6. 支持缓存、统计面板、demo 模式和证据沉淀目录

## 技术路线

### 第一阶段：最小闭环

- 上传文档
- 本地解析文本
- 云端模型处理
- 前端结果展示
- 本地日志留存

### 第二阶段：端云协同增强

- 页级结构化解析
- 文本分块
- 轻量检索
- 引用页码与来源说明

### 第三阶段：评测与比赛增强

- 检索与生成效果对比
- benchmark / 样例集
- 材料、脚本、证据包完善

## 差异点

研答通不是泛聊天壳，而是围绕文档任务闭环构建的助手：

- 有上传、解析、生成、日志闭环
- 有文档结构保留
- 有检索与引用基础
- 有可验证证据链和运行统计
