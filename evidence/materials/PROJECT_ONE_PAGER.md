# 研答通 一页式项目说明

## 一句话定义

研答通是一款面向科研与智能办公场景的个人智能文档助理，能够围绕上传文档完成摘要、问答、提纲生成，并逐步增强为带检索、带引用、可评测的端云协同文档系统。

## 作品定位

- 作品形态：个人智能助理
- 当前载体：Web 应用
- 目标场景：科研学习、智能办公、汇报答辩准备

## 目标用户

- 需要快速理解论文、方案、报告的学生与研究者
- 需要从制度、通知、资料中快速提取答案的办公用户
- 需要生成汇报提纲、答辩提纲的知识工作者

## 核心痛点

1. 长文阅读成本高，重点分散，用户很难快速把握关键信息。
2. 传统聊天工具脱离文档上下文，回答缺少依据，难以验证。
3. 汇报提纲、答辩提纲依赖人工整理，效率低且质量不稳定。

## 当前解决方案

### 输入层

- 支持上传 `TXT / Markdown / PDF`
- 保留文档原始文件、本地解析文本、页级结构化结果和文本分块结果

### 智能处理层

- 摘要：生成结构化摘要
- 问答：基于轻量检索选取相关片段，再调用模型回答
- 提纲：围绕文档内容生成汇报或答辩提纲

### 可解释性与工程能力

- `ask` 已支持结构化引用依据，返回页码与证据片段
- `summary / outline` 已支持来源片段展示
- 本地日志记录耗时、模型、token、结果类型、检索状态
- 统计面板可展示请求数、有效回答数、拒答数、错误数和延迟

## 差异点

研答通不是简单的聊天壳，而是围绕“文档任务闭环”构建的产品：

1. 有上传、解析、生成、日志留痕的完整链路
2. 有页级结构保留、文本分块和轻量检索
3. 有引用页码/证据片段，强调答案可验证
4. 有 demo 模式、统计面板、证据目录，便于展示和答辩

## 技术路线

### 第一阶段：最小闭环

- 上传文档
- 本地解析
- 云端模型处理
- 前端结果展示
- 本地日志留存

### 第二阶段：端云协同增强

- 页级结构化解析
- 文本分块
- 轻量检索
- 结构化引用与来源片段

### 第三阶段：评测与比赛增强

- 样例集与 benchmark
- 证据包与实验记录
- 路线表达、演示脚本、答辩材料完善

## 当前成果

- MVP 已端到端跑通
- 真实模型链路已验证
- 摘要 / 问答 / 提纲均可稳定演示
- 问答支持结构化引用依据
- 摘要 / 提纲支持来源片段展示
- 后端测试已覆盖核心服务和 API 路径
- 已沉淀截图、日志、接口、统计与材料文档
