# 固定样例集

## 样例 1：科研项目简介

- 文档类型：Markdown
- 任务：
  - 摘要：请用 3 条要点总结这个文档
  - 问答：这个项目第一阶段要做什么？
  - 提纲：请生成一个 5 页汇报提纲
- 价值：
  - 适合演示摘要、问答、提纲全链路

## 样例 2：制度/通知文档

- 文档类型：TXT
- 任务：
  - 摘要：请概括制度的核心要求
  - 问答：关于请假流程有哪些规定？
  - 提纲：请整理成培训提纲
- 价值：
  - 适合演示办公场景

## 样例 3：论文或报告 PDF

- 文档类型：PDF
- 任务：
  - 摘要：请概括研究背景、方法和结论
  - 问答：这篇文档的核心方法是什么？
  - 提纲：请生成答辩提纲
- 价值：
  - 适合演示 PDF 页级结构和引用依据

## 演示建议

- 每次演示固定使用同一批文档和提示词
- 先展示摘要，再展示问答引用，再展示提纲
- 每个样例都保留截图、日志与统计
