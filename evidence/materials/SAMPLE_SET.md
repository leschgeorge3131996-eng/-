# 固定样例集

## 使用原则

- 每次演示固定使用同一批文档和提示词
- 每个样例都至少演示：摘要、问答、提纲三类任务
- 每个样例都保留：
  - 前端截图
  - 调用日志
  - 统计面板数据

## 当前优先级

- 如果目标是比赛演示稳定性，而不是一般能力覆盖，优先使用：
  - `evidence/materials/GOLD_SAMPLE_RUNBOOK.md`
  - `evidence/materials/GOLD_SAMPLE_CANDIDATE_20260418.json`
- 当前锁定的 gold-sample candidate 就是下面的“样例 4：中文论文 PDF”

## 样例 1：科研项目简介

- 文档类型：Markdown
- 适合展示：
  - 基础摘要
  - 基于文档内容的问答
  - 汇报提纲生成
- 固定提示词：
  - 摘要：`请用 3 条要点总结这个文档。`
  - 问答：`这个项目第一阶段要做什么？`
  - 提纲：`请生成一个 5 页汇报提纲。`
- 亮点：
  - 适合做“完整闭环”的主演示样例

## 样例 2：制度/通知文档

- 文档类型：TXT
- 适合展示：
  - 办公文档中的规则提炼
  - 规则问答
  - 培训提纲生成
- 固定提示词：
  - 摘要：`请概括制度的核心要求。`
  - 问答：`关于请假流程有哪些规定？`
  - 提纲：`请整理成培训提纲。`
- 亮点：
  - 适合体现智能办公场景，不局限于科研论文

## 样例 3：论文或报告 PDF

- 文档类型：PDF
- 适合展示：
  - 页级结构保留
  - 轻量检索
  - 引用页码和证据片段
- 固定提示词：
  - 摘要：`请概括研究背景、方法和结论。`
  - 问答：`这篇文档的核心方法是什么？`
  - 提纲：`请生成答辩提纲。`
- 亮点：
  - 适合重点展示“不是聊天壳，而是基于文档和页码的助手”

## 样例 4：中文论文 PDF

- 文档类型：PDF
- 文件：
  - `evidence/samples/chinese_llm_spatial_eval.pdf`
- 适合展示：
  - 中文学术内容解析
  - 中文问答
  - 中文摘要与提纲
- 推荐提示词：
  - 摘要：`请概括这篇论文的研究背景、方法和主要结论。`
  - 问答：`这篇论文主要研究了什么问题？`
  - 提纲：`请生成一个中文汇报提纲。`
- 亮点：
  - 用于验证系统不仅能处理英文经典论文，也能处理中文学术 PDF

## 演示顺序建议

1. 比赛/评审优先：先用样例 4 走锁定的 gold-sample candidate
2. 如果要补充一般能力覆盖，再用样例 1 走完整闭环
3. 再用样例 3 强调页码引用和证据片段
4. 如果时间足够，再补样例 2 说明办公场景扩展性
