# 研答通海报文案稿

## 标题

`研答通`

## 副标题

`让每条回答都能回到 PDF 原文证据`

## 一句话摘要

面向论文阅读、报告复核、答辩准备的文档问答助手。核心不是泛化聊天，而是让回答、citation 与 PDF 原文证据形成闭环。

## 模块一：为什么要做

建议标题：

`为什么现有工具还不够`

正文文案：

- 长文阅读成本高，关键信息分散。
- 普通聊天工具能回答，但很难证明答案来自原文。
- 在答辩和汇报场景里，真正重要的是“说得出依据”。

## 模块二：怎么做

建议标题：

`一条可验证的主链路`

正文文案：

1. 上传论文或报告。
2. 保留页级结构并完成分块解析。
3. 针对问题检索相关证据片段。
4. 返回回答、citation 和证据区。
5. 点击 citation 跳回 PDF 原页。
6. 检索无命中时直接拒答。

流程图建议：

`upload -> ask -> citation -> PDF -> refusal`

## 结尾短句

## 排版建议

- 上方：标题、副标题、一句话摘要
- 中部：问题背景 + 系统路径
- 下方：真实样例截图 + 当前结论
- 角落：可放 `gold_sample_replay_real_summary_latest.md` 的二维码或短链接

## 不要写进海报的话

- 不要强调登录、邀请码或 demo 边界。
- 不要把 broader replay 当作主结论。
- 不要把 `summary / outline` 讲成和 `ask` 一样强的证据语义。
